# Documento 3 — Design System: Liquid Glass

> Versión 1.0

## Objetivo

Crear un sistema visual elegante, moderno, sobrio y consistente que transmita
paz, confianza y cercanía con Dios. Toda pantalla de QFaith deberá seguir este
documento.

## Filosofía de diseño

La interfaz nunca deberá sentirse religiosa de manera exagerada.

**No utilizar:** cruces gigantes, nubes, rayos de luz, palomas, ángeles, fondos
recargados, imágenes religiosas como decoración permanente.

**La aplicación deberá sentirse:** moderna, elegante, minimalista, premium,
tranquila, humana.

## Estilo

Inspiración: Apple Human Interface · Liquid Glass · Notion · NordPass ·
Monarch Money · Wallet de Apple · Material Design 3 (solo como referencia de
accesibilidad).

## Colores

| Rol | Color | Uso |
| --- | --- | --- |
| Principal | Azul profundo | Botones principales, enlaces, estados activos |
| Secundario | Verde oliva suave | Hábitos, progreso, respuestas de oración |
| Espiritual | Dorado tenue (nunca brillante) | Solo para pequeños detalles |

### Fondos

- **Modo claro:** blanco cálido, gris muy claro, cristal translúcido.
- **Modo oscuro:** azul noche, negro grafito, cristal oscuro.

### Colores de estado

Éxito: verde · Advertencia: ámbar · Error: rojo suave · Información: azul

Nunca utilizar colores extremadamente saturados.

## Tipografía

- **Fuente principal:** Inter
- **Fuente para títulos espirituales:** Merriweather

Jerarquía: título principal · título secundario · subtítulo · texto · nota ·
pie de página.

**Nunca utilizar más de dos familias tipográficas.**

## Iconografía

Iconos lineales. Nunca caricaturescos. Nunca religiosos exagerados. Todos
deberán compartir el mismo estilo.

## Bordes

Todos los componentes tendrán bordes redondeados. Nunca esquinas completamente
rectas.

## Efecto Liquid Glass

Todas las tarjetas tendrán: transparencia moderada, desenfoque, brillo suave,
sombras ligeras.

**Nunca exagerar el efecto.**

## Botones

Tres tipos: primario, secundario, texto.

Todos deberán compartir altura, radio, tipografía y animación.

## Campos de texto

Borde suave. Fondo translúcido. Icono opcional.

Estados: normal, activo, error, deshabilitado.

## Tarjetas

Cristal, sombra ligera, borde fino, espaciado amplio.

Nunca utilizar tarjetas completamente opacas.

## Espaciado

Todo el sistema utilizará una cuadrícula consistente. Nunca colocar componentes
demasiado juntos. La aplicación deberá respirar.

## Animaciones y transiciones

Animaciones lentas, naturales, suaves, elegantes. Nunca llamativas.

Transiciones: fade, slide, scale. Nunca rebotes exagerados.

## Navegación

Barra inferior con cinco pestañas: Inicio · Biblia · Oración · IA · Perfil.

La barra deberá utilizar efecto cristal.

## Pantalla de inicio

Mostrar: saludo, versículo, estado espiritual, resumen diario, accesos rápidos.
Todo sin saturar la pantalla.

## Modo oscuro

No invertir simplemente colores. Diseñar específicamente para modo oscuro.

## Ilustraciones e imágenes

Ilustraciones minimalistas, modernas, colores suaves. Nunca infantiles.

Imágenes: solo utilizar cuando realmente aporten valor. Evitar fotografías
genéricas.

## Accesibilidad

Compatible con modo oscuro, texto grande, lectores de pantalla y alto
contraste.

## Consistencia

Todos los componentes deberán reutilizarse. Nunca crear dos estilos distintos
para el mismo botón. Nunca crear tarjetas diferentes para funciones similares.

## Microinteracciones

Los botones responderán con pequeñas animaciones. Las tarjetas reaccionarán
suavemente al tocarse. Las cargas mostrarán indicadores elegantes.

Nunca bloquear completamente la interfaz.

## Notificaciones visuales

Discretas, elegantes, no invasivas. Nunca interrumpir momentos de oración o
lectura.

## Objetivo final

El usuario deberá sentir que está utilizando una aplicación premium, moderna y
extremadamente cuidada, donde cada detalle transmite serenidad, confianza y
calidad.
